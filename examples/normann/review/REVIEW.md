# Вариант A — «Лоция»

## Вердикт: Показывать после правок

Самая собранная система из четырёх. Экран сделан как лоция: слева заголовок, справа кадр в тонкой рамке с выносками «точка → линия → подпись», внизу таблица фактов. Всё на одной сетке, с крестиками по углам, есть живое время. Главная слабость — фото. Это Рейнисфьяра в Исландии: узнаваемые кекуры Рейнисдрангар и травяной обрыв. Кадр подписан как берег у отеля, а у Териберки нет чёрного песчаного пляжа с зелёными обрывами. Для варианта, где вся идея — точная карта места, это подрывает доверие. Ещё сломан мобильный: выноска вылезает за экран, рамка наезжает на таблицу.

## Первые 5 секунд

Отель у холодного моря «на краю карты». Понятно за 2–3 секунды: крупный H1 слева, справа берег. Глаз идёт так: H1 → оранжевая точка «вы здесь» → чёрная кнопка «Выбрать даты». Куда нажать — понятно, кнопка дублируется в шапке. На что похоже: технический чертёж или навигационная карта, но теплее за счёт слов «тёплый дом». Выглядит дорого и аккуратно, не шаблон. Минус настроения: пасмурный летний день — ни сияния, ни ночи. Три из четырёх опор брифа есть только в тексте.

## Три решения с наибольшим эффектом

1. **Поставить в рамку настоящую Териберку** (D-шные кадры Ninara) и перерасставить выноски по реальным местам. Идея «лоции» заработает на полную силу.
2. **Починить мобильную раскладку** (Б1, В2, В3) — сейчас на телефоне экран выглядит сломанным.
3. **H1 в три строки и таблица фактов в пределах экрана на ноутбуке 1280×800** (В5, В6).

## Находки

### Блокеры

**Б1. 390 · выноска «A · 0,8 км — Скалы-кекуры».** Подпись вылезает за правый край: ширина документа 425px при окне 390, текст обрезан до «Скалы-кек». *Почему:* горизонтальный скролл и обрезанный текст — поломка вёрстки. *Правка:* первой выноске дать класс `pin--flip-s` и развернуть её на телефоне: точка справа, подпись слева.
```css
@media (max-width: 600px) {
  .pin--flip-s { left: auto !important; right: 25%; flex-direction: row-reverse; }
}
```
Проверено подстановкой: выноска встаёт в 133–284px и умещается в кадр.

### Важно

**В1. Все ширины · главный кадр.** Это Рейнисфьяра (Исландия), а подписан он как «Чёрный пляж», «Скалы-кекуры» и «вы здесь — Норманн». *Почему:* идея лоции — точная карта места; чужой берег узнает каждый, кто был в Исландии или в Териберке. Честность — ядро этого варианта. *Правка:* заменить на реальный кадр Териберки. Лучше всего подходит `img/d-boats.webp` (кладбище кораблей, Ninara, CC BY 2.0): он уже 4:3, как рамка, а 779px при рамке ~890px на 1440 дают допустимое для демо увеличение. Выноски: «A · 300 м — Кладбище кораблей» на остовы, «B · 10 мин пешком — Бухта» на воду справа, «C · вы здесь — Норманн, 12 номеров» на склон у дороги (`left: 14%; top: 22%`), а не в прибой. Кредит: «Демо · фото: Ninara, CC BY 2.0». Другой вариант — панорама бухты `raw/photo-018.jpg` (1024×458) при рамке `aspect-ratio: 21/9`.

**В2. 768 и 390 · рамка кадра и таблица фактов.** Рамка наезжает на таблицу на 16px: верхняя линия `.log` закрыта, подпись «От Мурманска» прилипла к рамке (5px). *Почему:* в `@media (max-width:1100px)` у `.frame` стоят `height: 100%` и `margin-top: 2.5rem`, и вместе они выталкивают рамку за пределы figure. *Правка:*
```css
@media (max-width: 1100px) { .map { margin-top: 2.5rem; } .frame { margin-top: 0; } }
```

**В3. 390 · кнопка в шапке.** Остаётся только «→» в рамке: подпись скрыта `display:none`, стрелка `aria-hidden`, у ссылки нет ни видимого, ни доступного имени. *Почему:* посетитель не поймёт, что это бронь, а скринридер прочитает пустую ссылку. *Правка:* вместо скрытия — короткая подпись: `<span class="s-hide">Выбрать </span>даты`, CSS `@media (max-width:600px){ .book-top .s-hide{display:none} }` (убрать `.book-top .btn span{display:none}`), плюс `aria-label="Выбрать даты"`.

**В4. Все ширины · подпись рамки.** «Лист 1 · Берег к северу от отеля» противоречит выноске «C · вы здесь — Норманн» в том же кадре. «Масштаб 1:25 000» на перспективном фото ничего не означает. *Почему:* в варианте про точность любая неточность видна сразу. *Правка:* «Лист 1 · Берег у отеля» и вместо масштаба факт: «Вид на север · сентябрь».

**В5. 1440 · H1.** В колонке из 4 модулей заголовок рвётся на 5 строк, две из них — одиночные слова: «Последняя / точка / на карте / и тёплый / дом». *Почему:* рваная лесенка, заголовок занимает 360px высоты и душит лид. На 1920 те же слова в 3 строки смотрятся собранно. *Правка:*
```css
@media (min-width: 1101px) { .text { grid-column: 1 / 6; } .map { grid-column: 6 / -1; } .nav { grid-column: 6 / 10; } }
h1 { font-size: clamp(2.75rem, 1rem + 3.4vw, 4.75rem); }
```
Проверено: «Последняя точка / на карте / и тёплый дом».

**В6. 1280×800 и 1920×1080 · таблица фактов.** Таблица-лоция уходит под сгиб. *Почему:* кадр растёт по высоте самой картинки (922px на 1920), а таблица — главный носитель идеи и ответ на «как далеко и когда ехать». *Правка:* картинка не должна задавать высоту строки.
```css
.frame img { position: absolute; inset: 10px; width: calc(100% - 20px); height: calc(100% - 20px); }
@media (min-width: 1101px) { .chart { height: 100svh; min-height: 760px; } }
```

### Полировка

**П1. Моно-подписи капсом** набраны с `letter-spacing: .02em`, а капсу нужно .05–.08em. Правка: `.mono { letter-spacing: .06em; }`.

**П2. Компас:** белый на белом небе (контраст 1.3:1), буква «N» лезет на паспарту. Правка: `.compass { top: 40px; border-color: rgb(255 255 255 / .9); background: rgb(15 23 27 / .25); }` или убрать компас совсем.

**П3. 390 · подпись рамки** переносится в две строки и садится на рамку. Правка: `@media (max-width:600px){ .frame__cap span:last-child{display:none} .frame__cap{white-space:nowrap} }` вместе с укороченной подписью из В4.

**П4. Пунктирная сетка фона** проходит под лидом: горизонталь режет абзац. Правка: `.lead { background: var(--bg); box-shadow: 0 0 0 .5rem var(--bg); }`.

**П5. Диапазоны** набраны длинным тире с пробелами: «30.11 — 14.01», «сентябрь — март». Правка: «30.11–14.01», «с сентября по март».

**П6. Кредит** набран 11px и выпадает за 900px (страница 923px на 1440×900). Правка: `font-size: .75rem`, перенести внутрь последней ячейки `.log` или в строку подписи рамки.

## Не трогать

- **Выноски «точка → линия → подпись»** и оранжевый пульсирующий «вы здесь» — лучший ход из всех четырёх вариантов: его перескажут.
- **Таблица-лоция внизу** (расстояние, полярная ночь, сияние, время сейчас) — факты, которые снимают вопросы «как далеко / когда ехать».
- **H1 «Последняя точка на карте и тёплый дом»** со второй половиной серым — контраст «край земли / тепло».
- **Вторая кнопка «Как добраться»** попадает точно в главное возражение Териберки — дорогу.
- **Пара Inter Tight + JetBrains Mono, серебро, R1 2px, крестики по углам** — система проведена до мелочей, включая favicon.

**Самобытность:** с журналом ДНК нет ни одного полного совпадения по семи осям (шапка, первый экран, кнопки, шрифты, углы разные). Лёгкая перекличка с Куликовой — микро-слой в скобках «[01]» и время — не находка.

# Вариант B — «Пульт»

## Вердикт: Показывать после правок

Самый «продающий» экран. На первом экране есть выгода («Сияние видно из окна номера»), живой прогноз, счётчик до полярной ночи, наличие и цена. Тексты лучшие из четырёх. Слабость — в форме. Это тёмный SaaS-дашборд из стопки скруглённых карточек, по ДНК и настроению брат Selix. В кадре нет ни Териберки, ни дома, ни моря — только бледное сияние в шумах. Такой экран подходит приложению-прогнозу, а не «дому у моря».

## Первые 5 секунд

Ночь, сияние, мятная строка «из окна номера» — через секунду понятно: отель, откуда видно сияние. Глаз идёт так: мятная часть H1 → белая карточка брони справа внизу (самое яркое пятно) → мятная кнопка в шапке → «Kp 5». Куда нажать: «Забронировать» в шапке или белая карточка. У заголовка кнопки нет. На что похоже: Apple Weather или шаблон Framer-дашборда — аккуратно и технологично, но не «тёплый дом на краю».

## Три решения с наибольшим эффектом

1. **Заменить кадр** на яркое сияние с землёй — сопками, крышами, берегом (В1).
2. **Поставить кнопку «Выбрать даты» под H1** и свести бронь к одной формулировке (В3, В5).
3. **Уйти от ДНК Selix** — сменить углы и форму кнопки (В2).

## Находки

### Блокеры
Нет.

### Важно

**В1. Все ширины · главный кадр.** Сияние бледное, в высоком ISO-шуме (на 1920 зерно и мыло хорошо видны). Две трети кадра — пустое фиолетовое небо, земли нет. *Почему:* обещание «видно из окна номера» и чип «Прямой эфир с крыши отеля» картинкой не подтверждены: нет ни крыш, ни моря, ни сопок, вау-эффекта нет. *Правка:* кадр с ярким зелёным сиянием и землёй в нижней трети — сопки, дома или берег. Пока замены нет — `.stage > img { filter: contrast(1.12) saturate(1.25); }` и затемнить верх скрима до `rgb(6 9 18 / .5)`, чтобы шум меньше читался.

**В2. Самобытность · сравнение с Selix.** Полностью совпадают углы (R2, панели 18px). Частично — первый экран (ночной кадр в скруглённой панели на тёмном), шрифт (один гротеск T1; у Selix T1+T2) и кнопка («подпись + отдельный квадрат со стрелкой» — родня «таблетке + кругу ↗»). Рядом с Selix читается как тот же шаблон. *Почему:* правило журнала — варианты не должны повторять прошлые сайты. *Правка:* сменить ось углов на R1 — `--r: 6px`, `.tabs a, .cta { border-radius: 4px; }`, `.card--thumb img { border-radius: 4px; }`. Кнопку сделать сплошной мятной плашкой со стрелкой в тексте, без вложенного тёмного квадрата: `.cta span { background: none; color: inherit; width: auto; }`.

**В3. Первый экран · нет кнопки у заголовка.** Колонка `.stage__foot` под кнопку заложена, но пуста. Бронь есть только в шапке и в белой карточке в углу. *Почему:* путь «прочитал → нажал» рвётся, глаз уходит от H1 в правый нижний угол. *Правка:* во вторую колонку `.stage__foot` добавить `<a class="cta cta--lg" href="#">Выбрать даты <span aria-hidden="true">→</span></a>`, CSS `.cta--lg { height: 52px; font-size: 1rem; padding-left: 1.375rem; }`.

**В4. 1440/1920 · карточка «Киты у берега».** Под текстом дыра 70–140px: сетка `1.25fr 1fr 1fr auto` растягивает карточку, а миниатюра 84px висит сверху. Кит на ней — серое пятно. *Почему:* дыра выглядит как недоделка, а миниатюра не работает. *Правка:*
```css
.card--thumb { grid-template-columns: minmax(0, 1fr) 42%; align-items: stretch; padding-right: .625rem; }
.card--thumb img { width: 100%; height: 100%; min-height: 120px; }
```

**В5. Тексты · одно действие называется тремя способами:** «Забронировать» в шапке, «Свободно на выходные →» в карточке, «выбрать даты» в брифе. *Почему:* разные слова для одного действия — лишняя секунда сомнения. *Правка:* в шапке «Выбрать даты», в карточке строка-действие: «3 номера из 12 · от 14 000 ₽ — выбрать даты →».

**В6. 390 · чипы на фото.** Переносятся в две строки («Прямой эфир с крыши / отеля · демо», «69°09′ / с. ш.») и выглядят как сломанные таблетки. *Правка:* `@media (max-width:600px){ .chip{white-space:nowrap; font-size:.75rem} .stage__top .chip:last-child{display:none} }`.

### Полировка

**П1. `.lbl` с `letter-spacing: .04em` на строчных** — трекинг нужен только капсу; особенно заметно в предложении «Горбачи и косатки…». Правка: `.lbl { letter-spacing: .005em; }`.

**П2. Карточка китов:** «Июнь — октябрь» → «Июнь–октябрь». Строка «3 часа» повисает одна на второй строке — сократить: «Горбачи и косатки · катер, 3 часа».

**П3. «Kp 5»** — термин для охотников за сиянием, а не для всех. Правка: в `.card__row` — «Kp 5 — сильная активность», «Ясно после 22:00» перенести в подпись шкалы.

**П4. Активная вкладка «Сейчас»** белой плашкой — самый контрастный элемент шапки, спорит с кнопкой брони. Правка: `.tabs a[aria-current] { background: var(--card-2); color: var(--ink); }`.

**П5. Счётчик полярной ночи** зашит на `2026-11-30`: после 30 ноября 2026 карточка навсегда покажет «0 дней». Правка: считать ближайшее 30.11 (`new Date(\`${y}-11-30T00:00:00+03:00\`)`, а если дата прошла — `y + 1`), а с 30.11 по 14.01 показывать «Полярная ночь идёт · ещё N дней».

## Не трогать

- **H1 «Сияние видно из окна номера»** с мятной второй строкой — выгода в пяти словах.
- **«Будим ночью, если небо загорится»** — конкретный сервис, человеческий голос; лучшая строка всех вариантов.
- **«3 номера из 12 · от 14 000 ₽ за ночь»** — цена и дефицит на первом экране.
- **Живые часы и дата Териберки, прогноз Kp и счётчик до полярной ночи** — пульт действительно полезен тому, кто едет за сиянием.
- **Палитра ночь + мята и градиент шкалы** — цвет из картинки, а не «потому что тёмная тема».
- **Адаптив:** на 768 и 390 раскладка чистая, стопка карточек перестраивается правильно.

# Вариант C — «Рамка»

## Вердикт: Переделать (в текущем виде)

Формально: средний балл ниже 6 и сломан первый экран. При этом главная поломка механическая и чинится одной строкой CSS (проверено). После неё и после замены фото вариант выходит примерно на 6.5 — это самый смелый постер из четырёх. Но сейчас на любой ширине меньше ~1800px правая часть листа срезана: кнопка шапки «Вы…», подпись «Баренцево мор…», бейдж брони, последняя «Н» вордмарка. К тому же в кадре Альпы: острые скальные пики и каменно-деревянная хижина, моря нет, хотя подпись «Баренцево море».

## Первые 5 секунд

Ржавая рамка, огромное ржавое «НОРМАНН» на кромке кадра со снежными пиками и хижиной. Что это — непонятно. Слово «отель» есть только в белой 12-пиксельной подписи на светлом небе (контраст 2:1). Можно принять за бренд одежды, горный приют или пиво. Правый край обрезан, экран выглядит сломанным. Куда нажать — неочевидно: «Вы…» в шапке и вращающийся бейдж, который читается как декор. На что похоже: постер с Behance, сильный, но не про Териберку.

## Три решения с наибольшим эффектом

1. **Одна строка CSS против переполнения** (Б1) — вернёт экран целиком.
2. **Кадр Териберки с ржавчиной** — кладбище кораблей или рыжая тундра (В1): рамка обретёт смысл.
3. **Крупная строка «что это»** под вордмарком и **явная кнопка брони** (В2, В4).

## Находки

### Блокеры

**Б1. Все ширины меньше ~1800px · правая часть листа срезана.** Сломаны кнопка шапки «Выбрать даты», подпись «Баренцево море · 69° с. ш.», бейдж «Забронировать», последняя «Н» и кредит. *Почему:* у `.sheet` грид с неявной колонкой `auto`, а `.word { white-space: nowrap; font-size: 15.4vw }` шире листа (1476px при листе 1408 на 1440; 395 при 374 на 390). Колонка растягивается, `overflow: hidden` срезает лишнее. *Правка:*
```css
.sheet { grid-template-columns: minmax(0, 1fr); }
.word  { font-size: clamp(3rem, 13.6vw, 15.5rem); }
@media (max-width: 560px) { .word { font-size: 12.6vw; } }
```
Проверено на 1920/1440/1280/768/390: вордмарк влезает целиком (`scrollWidth = clientWidth`), кнопка и бейдж на месте.

### Важно

**В1. Все ширины · кадр.** Альпы: острые пики с ледником, каменно-деревянная хижина, моря нет, хотя подпись «Баренцево море». Кольские сопки низкие, округлые и безлесные. *Почему:* место — главный товар; ржавая рамка без ржавчины в кадре теряет смысл. *Правка:* `raw/photo-008.jpg` (кладбище кораблей — ржавчина буквально) или `raw/photo-002.jpg` (сопка в осенней тундре, рыже-оранжевые тона рифмуются с рамкой), оба Ninara, CC BY 2.0. Кредит поправить. 1024px — для демо допустимо; для продакшена нужна съёмка.

**В2. Первый экран · непонятно, что это.** H1 — одно имя. «Отель» есть только в подписи на фото, описание — мелким текстом в левом нижнем углу. *Почему:* тест пяти секунд не пройден. *Правка:* в `.foot` первой строкой крупно (Commissioner 500, 24–28px): «Отель на двенадцать окон у Баренцева моря», мелкий лид оставить ниже.

**В3. Подпись на фото «(01) Отель на двенадцать окон».** Белый капс 12px на светлом небе, контраст ≈2:1. *Правка:* `.shot::after { background: linear-gradient(180deg, rgb(20 14 10 / .55), transparent 24%); }`, чтобы контраст был ≥ 4.5:1.

**В4. Коммерция · главное действие.** В шапке — тонкая подчёркнутая ссылка «Выбрать даты», а вращающийся бейдж с другим текстом «Забронировать» читается как декор. *Правка:* текст бейджа — «Выбрать даты · Териберка · 69° с. ш. ·». В правую ячейку `.foot` вместо кредита поставить кнопку: `<a class="btn" href="#">Выбрать даты →</a>`, CSS `.btn{display:inline-flex;align-items:center;height:52px;padding:0 1.5rem;border-radius:999px;background:var(--rust);color:var(--sheet);font-weight:500}`. Кредит перенести строкой ниже, 12px.

**В5. Меню.** Карточка открывается, но кнопка не меняет состояние: остаётся «Меню», нет ×. Клик мимо меню не закрывает. *Правка:* в JS при открытии `b.lastChild.textContent = o ? 'Закрыть' : 'Меню'`, в CSS — иконка × по `[aria-expanded="true"]`, плюс `document.addEventListener('click', e => { if (!m.contains(e.target) && !b.contains(e.target)) { m.classList.remove('open'); b.setAttribute('aria-expanded', false); } });`.

**В6. 1920 (после Б1 — на всех широких экранах) · дыра ~150px между вордмарком и подвалом листа.** Строку `1fr` отдали пустоте под словом. *Правка:* кадр должен забирать свободную высоту.
```css
@media (min-width: 901px) {
  .hero { display: flex; flex-direction: column; }
  .shot { flex: 1 1 0; height: auto; min-height: clamp(320px, 50svh, 640px); }
  .shot img { position: absolute; inset: 0; }
}
```
Проверено: на 1440 лист ровно 868px, на 1920 — 1048px, без дыр.

**В7. 390 · бейдж лежит поверх конца вордмарка** («НОРМА…»). *Правка:* `@media (max-width:560px){ .badge{ top: calc(58svh - 150px); } }` — бейдж на фото, над словом.

**В8. Самобытность · углы R2** (лист 22px, кадр 14px) — одна ось из семи совпадает с Selix и с вариантом B. *Почему:* правило журнала — одно-два совпадения требуют решения. *Правка:* по желанию перейти на R1: `.sheet { border-radius: 6px; } .shot { border-radius: 4px; }`. Рамка от этого станет жёстче и «корабельнее»; остальная ДНК C (G9, C8, H6, N5, B5, T5) в журнале не встречается.

### Полировка

**П1. «45 дней ночи»** — непонятно, какой ночи. Правка: «45 дней полярной ночи».

**П2. «69° N» латиницей в бейдже** рядом с «69° с. ш.» на фото. Правка: «69° с. ш.».

**П3. Меню на 390:** строка контактов переносится так, что новая строка начинается с «·». Правка: телефон и почту — отдельными строками.

**П4. 390 · подписи на фото** в три строки. Правка: `@media (max-width:560px){ .shot__cap span:last-child{display:none} }`.

**П5. 390 · логотип и «Выбрать даты»** в шапке почти касаются друг друга. Правка: на ≤560 подпись «Даты →».

## Не трогать

- **Ржавая рамка + молочный лист** — самая новая для журнала ДНК система (G9/C8), и она рифмуется с ржавыми кораблями Териберки, когда в кадре будут корабли.
- **Вордмарк Unbounded 800, наползающий на нижнюю кромку кадра** — постерный ход, который запоминается (целиком виден на 1920 и после Б1).
- **«(01) Отель на двенадцать окон»** — поэтичнее и точнее, чем «12 номеров».
- **Три факта «12 / 45 / 130»** широким шрифтом — лаконично.
- **Меню-карточка тёмным поверх листа** — в системе.

# Вариант D — «Бортовой журнал»

## Вердикт: Показывать после правок

Самый душевный и единственный честный вариант: все фото — настоящая Териберка (кладбище кораблей, бухта, лодки, Ninara CC BY). Полароиды со скотчем, рукописные подписи-факты, ультрамариновые «чернила», штемпель. Но коллаж перегружен: двенадцать объектов на экране. Рукописная заметка с главным аргументом лежит прямо на буквах вордмарка. Лид закрывает кита. На 768 и 390 раскладка разваливается: штемпель наезжает на текст, в середине дыра. Кнопка брони маленькая и находится последней.

## Первые 5 секунд

Крафт-бумага, полароиды с северным морем и ржавыми кораблями, огромное синее «Норманн» курсивом и «дом у Баренцева моря». Сразу понятно: место у северного моря, дневник путешественника. Что это отель — из бокового «Отель · Териберка» и лида. Глаз идёт так: синий вордмарк → «дом у Баренцева моря» → прыгает по пяти фото → штемпель → оранжевый стикер последним. Центров внимания больше десяти. Куда нажать — находишь на 4–5-й фиксации. На что похоже: скрапбук с Behance, тепло и вручную, точно не шаблон.

## Три решения с наибольшим эффектом

1. **Развести столкновения и убрать шум** — штемпель, стрелку, заметку с заголовка (Б1, В2).
2. **Перевести 641–1100 на поток, как у телефона** (Б2) — планшет перестанет разваливаться.
3. **Кнопка «Выбрать даты» в шапке/индексе** на всех ширинах (В3).

## Находки

### Блокеры

**Б1. 1280/1440/1920 · рукописная заметка.** «двенадцать номеров, у каждого своё окно на море» лежит на буквах «р·м» вордмарка, стрелка перечёркивает «у». *Почему:* главный аргумент — окно на море у каждого номера — не читается и выглядит как ошибка вёрстки. *Правка:* `.n1 { left: 3%; top: 58%; --r: -4deg; }`, `.arrow { display: none; }`. Заметку «сияние — с сентября по март», которая касается «моря», опустить: `.n2 { top: 59%; }`. Штемпель убрать (см. В2), иначе на 1440 он коснётся заметки. Проверено на 1280/1440/1920: заметка встаёт под второй строкой заголовка, пересечений нет.

**Б2. 768 и 390 · раскладка разваливается.** На 768 штемпель наезжает на лид (53–235 × 804–986 против 18–402 × 923–1062), стрелка указывает в пустоту, в середине дыра ~400px, кнопка у нижнего края. На 390 штемпель лежит поверх «Норманн» и строки координат. *Почему:* абсолютный коллаж держится до 1100px, а поток включается только с 640. *Правка:* перенести мобильный поток на `@media (max-width: 1100px)` и дать три колонки для планшета.
```css
@media (max-width: 1100px) {
  .spread { min-height: 0; display: grid; gap: 1rem; padding-bottom: 3rem; }
  .title, .cut, .stamp, .note, .lede { position: relative; left: auto; right: auto; top: auto; bottom: auto; width: auto; }
  .title { order: -1; margin-top: 1rem; font-size: min(22vw, 11rem); }
  .collage { display: grid; grid-template-columns: repeat(3, 1fr); gap: 1.25rem .75rem; margin-top: .5rem; align-items: start; }
  .cut { width: auto !important; } .c4, .c5 { display: none; }
  .stamp, .n1, .n2, .arrow { display: none; }
  .lede { width: auto; max-width: 34rem; margin-top: .5rem; }
  .credit { position: static; }
}
@media (max-width: 640px) { .collage { grid-template-columns: 1fr 1fr; } .c3 { grid-column: 1 / -1; } }
```
Проверено: на 768 чисто, кнопка на 893px (в пределах 1024).

### Важно

**В1. 1440 · лид с кнопкой лежит поверх полароида с китом.** Хвост закрыт, «кит! июль» подписывает пустое море. *Правка:* `@media (min-width:1101px){ .lede{ left: 50%; } .c5{ right: 2%; } }`. Проверено: лид 816–1168px, полароид 1208–1421px, кит виден.

**В2. 1280–1920 · шум: двенадцать объектов на экране** (5 фото, вордмарк, подзаголовок, штемпель, 2 заметки, стрелка, стикер). *Почему:* больше трёх центров внимания — CTA находится последним. Штемпель дублирует логотип. *Правка:* `.stamp { display: none; }`, стрелку убрать (Б1). Останется: вордмарк → фото → заметки → стикер.

**В3. Коммерция · единственная кнопка** — стикер 159×52 в правом нижнем углу. На 768/390 в шапке кнопки нет (у `.side` колонка `1fr auto`, вторая пуста). На 390 стикер ниже сгиба (897px при экране 844). *Правка:* в `.side` добавить `<a class="sticker sticker--s" href="#">Выбрать даты →</a>`, CSS `.sticker--s { transform: none; padding: .7rem 1rem; font-size: .75rem; }`. На десктопе он встаёт в индекс над «Лист 01 / 06», на ≤1100 — вправо шапки.

**В4. 390 · подзаголовок «дом у Баренцева моря»** в две строки с интерлиньяжем .8, унаследованным от `.title`: «моря» наезжает на «Баренцева». *Правка:* `.title span { line-height: 1; }`.

**В5. 390 · полароид «кладбище кораблей»** растянут по высоте соседнего портретного: под снимком пустое белое поле ~90px, подпись оторвана. *Правка:* `.collage { align-items: start; }`.

**В6. Самобытность · сравнение с «Нерпой» (Байкал, тоже северный отель).** Совпадают шрифт (T3 — антиква с курсивом как главный голос) и углы (R0). Частично — первый экран (много фото + антиква поверх) и цвет (C3, бумага). В одном портфолио читается как одна рука. *Правка:* сменить ось шрифта. Вордмарк прямым начертанием (`.title { font-style: normal; }`, курсив оставить только в подзаголовке) или крупным моно-капсом IBM Plex Mono 500, как штамп судового журнала. Тогда совпадение останется одно — R0.

**В7. Тексты · «вид из окна»** под снимком гнилой рамы заброшенного дома читается как «вот ваш номер» — отель выглядит руиной. *Правка:* подпись «окно старой избы, 5 минут от нас» или другой кадр — вид из современного окна.

### Полировка

**П1. Плашка лида** без боковых полей (`padding: .25rem 0`) — буквы прилипают к краю. Правка: `.lede p { padding: .35rem .6rem; margin-inline: -.6rem; }`.

**П2. Рукопись Caveat** на пяти подписях и двух заметках — много. Правка: одну заметку («сияние…») перевести в лид обычным текстом.

**П3. Пустой alt** у «вид из окна» и «утро, лодки», хотя фото содержательные. Правка: `alt="Вид на тундру из окна деревянного дома"`, `alt="Лодки на берегу бухты утром"`.

**П4. Кредит 11px.** Правка: `font-size: .75rem`. Для CC BY атрибуция обязательна — пусть читается.

## Не трогать

- **Настоящие кадры Териберки** (кладбище кораблей, бухта, лодки) — единственный вариант, где место настоящее; это сразу доверие.
- **Полароиды со скотчем и рукописными подписями-фактами** («бухта, 10 минут пешком», «кит! июль») — микро-слой несёт смысл.
- **Боковое оглавление 01–06 и «Лист 01 / 06 · Сезон 2026–27»** — журнальная метафора проведена в навигацию.
- **Ультрамариновые «чернила» с `mix-blend-mode: multiply`** поверх фото — вордмарк живёт на бумаге, как отпечаток.
- **Оранжевый стикер с жёсткой тенью** — кнопка в системе скрапбука, только её надо сделать заметнее (В3).

## Какой вариант самый сильный для отеля в Териберке

**A «Лоция».** По среднему баллу B выше на 0.2, но как направление A сильнее. Три причины:

1. **Идея принадлежит месту.** «Последняя точка на карте», выноски «вы здесь», лоция с расстоянием и полярной ночью — это язык края земли и моря, а не язык приложения. B — хороший, но типовой дашборд, его идея переносится на любой отель с сиянием. К тому же B близок к Selix.
2. **Путь к брони самый чистый.** Две кнопки у заголовка, та же кнопка в шапке и «Как добраться» — ответ на главное возражение Териберки (130 км по тундровой дороге). У D одна маленькая кнопка теряется в коллаже, у C кнопка срезана.
3. **Слабости A чинятся за час, у B — нет.** Замена фото и три CSS-правки против смены самой формы у B. У D надо перебрать коллаж, у C — починить переполнение и заменить кадр, а после этого ещё проверять, работает ли постер.

D — самый душевный и правдивый: если заказчику важнее эмоция, чем ясность, его стоит показать вторым, после Б1/Б2/В1–В3. C после одной строки CSS и замены кадра на кладбище кораблей становится сильным «диким» вариантом для презентации — самый запоминающийся постер.
