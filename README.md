# Prodamus-env

## Скиллы

### `festival-landing`

Скилл мастера-дизайнера для создания фестивальных лендингов — громких, постерных, «как на афише».

Собран разбором 13 самых залайканных проектов галереи [#madeontilda](https://tilda.cc/ru/madeontilda/) за сентябрь 2025 — сентябрь 2026 (из 972 опубликованных за период). Палитры сняты квантизацией полностраничных скриншотов, гарнитуры — из CSS проектов, приёмы — визуальным разбором.

```
.claude/skills/festival-landing/
├── SKILL.md                      процесс из пяти шагов и правила
├── references/
│   ├── research.md               разбор 13 источников: что откуда взято
│   ├── archetypes.md             пять архетипов и их границы
│   ├── palettes.md               13 реальных палитр с долями площади
│   ├── typography.md             роли, шкала, кириллические гарнитуры
│   ├── moves.md                  22 приёма с готовым CSS
│   ├── sections.md               архитектура страницы
│   └── anti-patterns.md          29 анти-паттернов
└── assets/
    ├── tokens.css                база проекта
    └── starter.html              рабочий скелет, проверен на 1440 и 390
```

Скилл подхватывается автоматически, когда речь заходит о лендинге для события, фестиваля, конференции, премии, воркшопа, спецпроекта или о просьбе сделать «модно», «дерзко», «в фестивальном стиле».
