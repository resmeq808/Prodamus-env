# Prodamus-env

Скиллы Claude для вёрстки лендингов. Каждый собран разбором реальных сайтов: полностраничные скриншоты, HTML, CSS, вычисленные палитры и типографические шкалы.

## `airy-landing` — премиальный сайт на всю ширину

Современный коммерческий сайт уровня лучших концептов Behance и Dribbble: кадр на всю панель с обработкой, гигантская типографика лесенкой, слой мелких подписей, стекло поверх фото, фото-карточки, светлый лист на тёмной странице, вордмарк в подвале. Сетка, ритм и детали — по нормам реальных сайтов.

Два источника:
- **замеры 343 сайтов** (266 в анализе) — Stripe, Linear, Apple, Mercury и другие в семи вертикалях: вычисленные стили в Chromium 1440×900, разбор открытых дизайн-скиллов (frontend-design, taste-skill, impeccable, ui-ux-pro-max). Это пол качества;
- **доска Pinterest пользователя** (58 разобранных пинов Behance/Dribbble) — художественная планка: пять направлений, двенадцать приёмов, тест на нейрослоп.

```
.claude/skills/airy-landing/
├── SKILL.md                  пять законов, процесс «мудборд → направление → кадры → сборка → проверка»
├── references/
│   ├── art-direction.md      ГЛАВНЫЙ: направления, 12 приёмов с кодом, фото, тест на нейрослоп
│   ├── system.md             палитры, шрифты с кириллицей, шкала, сетка, ритм, радиусы
│   ├── blocks.md             утилитарные секции с кодом
│   ├── copy.md               формулы заголовков, кнопки, тон
│   ├── details.md            30 деталей аккуратности
│   ├── anti-patterns.md      стерильность + 50 тэллов шаблона
│   ├── research.md           методика, медианы по вертикалям, разбор доски
│   └── dataset.csv           сырые замеры 266 сайтов
├── assets/
│   ├── starter.html + img/   эталонная сборка «Кинематограф» (фото CC0), проверена на 1440 / 768 / 390
│   └── tokens.css            база + классы приёмов доски
└── scripts/
    ├── moodboard.py          мудборд из любой доски Pinterest
    ├── find-photos.py        свободные фото CC0: поиск, контактный лист, скачивание
    ├── inline-assets.py      один HTML со встроенными картинками — для показа
    └── measure.js            замер любого сайта тем же методом (Playwright)
```

## `art-review` — ревью арт-директора

Придирчивый разбор готовой страницы свежим взглядом: скриншоты на 1440 / 768 / 390, механическая проверка (перекрытия, висячие слова, контраст, битые ссылки, кнопки в две строки, трекинг, мыльные картинки), затем разбор по десяти осям — идея, первый экран, композиция, типографика, изображения, цвет, ритм, детали, тексты, коммерческая логика. Оценки, вердикт, находки «блокер / важно / полировка» с конкретными правками, по запросу — правки.

```
.claude/skills/art-review/
├── SKILL.md                  роль, процесс, шкала, правила ревьюера
├── references/
│   ├── checklist.md          десять осей, ~90 вопросов
│   ├── copy-review.md        редактура смысла и русской типографики
│   └── report-template.md    формат отчёта
└── scripts/
    └── capture.js            скриншоты и механическая проверка (Playwright)
```

## `visual-prompter` — промты визуала для Gemini

Концептуальный визуал без API: скилл спрашивает, сколько генерировать (минимум / частично / много / полный арт-пакет), выводит визуальную идею и единый блок стиля, составляет съёмочный лист под вёрстку и пишет подробные промты для Gemini (Nano Banana / Nano Banana Pro) — фото для hero и карточек, фоны, текстуры, орнаменты, 3D-объекты, аватары. Пользователь генерирует по очереди и возвращает картинки; скилл принимает их (дефекты ИИ, серия, зона текста), пишет промты-правки и обрабатывает кадры в серию. Основа — разбор цвета, фактур и стиля фото 335 сайтов, 58 пинов доски и 33 референсов и официальные гайды Google.

```
.claude/skills/visual-prompter/
├── SKILL.md                  процесс: объём → стиль → съёмочный лист → промты → приёмка → обработка
├── references/
│   ├── gemini.md             модели, форматы, формула промта, шаблоны, правки, ограничения
│   ├── styles.md             десять стилей с готовыми блоками стиля
│   ├── palettes.md           цвет: цифры разбора, как вывести палитру, hex в промте
│   ├── backgrounds.md        фоны, подложки, текстуры, орнаменты, 3D-объекты
│   ├── shot-lists.md         форматы слотов и съёмочные листы по типам страниц
│   ├── review.md             приёмка: дефекты ИИ, серия, промты-правки
│   ├── research.md           разбор визуала сайтов и референсов
│   └── example-selix.md      полный пакет промтов для демо Selix
└── scripts/
    └── intake.py             кадрирование с фокусом, обработка серии, зерно, WebP, контактный лист
```

## `industrial-landing` — коммерция производственных компаний

Сдержанный, плотный, доказательный лендинг: тёмное фото реального производства, один деловой акцент, цифры с расшифровкой, карточки направлений, каталог, подбор.

Собран разбором **16 сайтов**: izhorastalinvest.ru, irstone.pro, monaer-russia.ru, trust-pay.ru, easybuild.by, blackwood.dev, propoly.pro, brick-art.ru, stanisla.ru, woodpecker-shop.tilda.ws, data-point.ru, artemlysenko.com, главный-путь.рф, airdog.m-mukhanov.ru, kurs.m-mukhanov.ru, siding-moldova.md.

```
.claude/skills/industrial-landing/
├── SKILL.md                  три закона жанра, процесс, правила
├── references/
│   ├── research.md           разбор 16 сайтов + пять вертикалей
│   ├── system.md             палитры, шрифты, шкала, сетка, кнопки
│   ├── blocks.md             21 блок с готовым HTML и CSS
│   ├── copy.md               тексты: заголовки, числа, кнопки, тон

│   └── anti-patterns.md      35 анти-паттернов
└── assets/
    ├── tokens.css            база проекта
    └── starter.html          рабочий скелет, проверен на 1440 / 768 / 390 / 360
```

## `festival-landing` — событийная афиша

Громкий постерный лендинг: плакатная типографика, один кислотный акцент, коллаж, наклейки, бегущие строки, свечение. Для фестивалей, конференций, премий, воркшопов, спецпроектов.

Собран разбором 13 самых залайканных проектов галереи [#madeontilda](https://tilda.cc/ru/madeontilda/) за сентябрь 2025 — сентябрь 2026 (из 972 опубликованных за период).

```

├── SKILL.md
├── references/   research · archetypes · palettes · typography · moves · sections · anti-patterns
└── assets/       tokens.css · starter.html
```

## Как выбрать

| Задача | Скилл |
|---|---|
| SaaS, финтех, товар, отель, студия, сервис — «премиально, как на Behance», референсы с Pinterest | `airy-landing` |
| Завод, подряд, оборудование, логистика, B2B-поставки | `industrial-landing` |
| Фестиваль, конференция, премия, спецпроект, лонгрид | `festival-landing` |
| Сгенерировать фото, фоны, текстуры и объекты для сайта в Gemini | `visual-prompter` |
| Проверить готовую страницу перед показом, найти недочёты | `art-review` |

Все подхватываются автоматически по формулировке задачи.
