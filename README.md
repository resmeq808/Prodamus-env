# Prodamus-env

Скиллы Claude для вёрстки лендингов и готовые страницы в фирменных стилях. Каждый
собран разбором реальных сайтов: полностраничные скриншоты, HTML, CSS, вычисленные
палитры и типографические шкалы.

## `industrial-landing` — коммерция производственных компаний

Сдержанный, плотный, доказательный лендинг: тёмное фото реального производства, один деловой акцент, цифры с расшифровкой, карточки направлений, каталог, подбор.

Собран разбором **16 сайтов**: izhorastalinvest.ru, irstone.pro, monaer-russia.ru, trust-pay.ru, easybuild.by, blackwood.dev, propoly.pro, brick-art.ru, stanisla.ru, woodpecker-shop.tilda.ws, data-point.ru, artemlysenko.com, главный-путь.рф, airdog.m-mukhanov.ru, kurs.m-mukhanov.ru, siding-moldova.md.

```
.claude/skills/industrial-landing/
├── SKILL.md                  три закона жанра, процесс, правила
├── references/
│   ├── research.md           разбор 16 сайтов + пять вертикалей
│   ├── system.md             палитры, шрифты, шкала, сетка, кнопки
│   ├── blocks.md             21 блок с готовым HTML и CSS
│   ├── copy.md               тексты: заголовки, числа, кнопки, тон
│   ├── photography.md        что снимать, как обрабатывать, иконки
│   └── anti-patterns.md      35 анти-паттернов
└── assets/
    ├── tokens.css            база проекта
    └── starter.html          рабочий скелет, проверен на 1440 / 768 / 390 / 360
```

## `festival-landing` — событийная афиша

Громкий постерный лендинг: плакатная типографика, один кислотный акцент, коллаж, наклейки, бегущие строки, свечение. Для фестивалей, конференций, премий, воркшопов, спецпроектов.

Собран разбором 13 самых залайканных проектов галереи [#madeontilda](https://tilda.cc/ru/madeontilda/) за сентябрь 2025 — сентябрь 2026 (из 972 опубликованных за период).

## `pages/social-responsibility` — страница «Социальная ответственность Prodamus»

Готовая страница в фирменном стиле Prodamus: один самодостаточный `index.html`
со встроенным CSS, без сборки и зависимостей. Открывается двойным кликом,
годится и на вставку в Tilda, и верстальщику в работу.

```
pages/social-responsibility/
├── index.html        вся страница: разметка + фирменные токены + CSS
└── assets/           логотипы партнёров, бейджи премий, сканы писем
```

Дизайн-система и **структура вёрстки** сняты с живых страниц `prodamus.ru`
(`/company`, `/platezhnaya-systema`, `/priem-rekurrentnyh-platezhej`), а не
восстановлены по памяти.

Главный принцип жанра: страница — это **стопка скруглённых подложек**.

| Что | Значение с сайта |
|---|---|
| Подложка секции | 1910px на артборде 1920 → зазор **5px** до края экрана |
| Радиус подложки | **40px**, на мобильном (350 на 360) — **20px** |
| Зазор между подложками | 20px |
| Сращивание | соседние подложки одного цвета: `40 40 0 0` + `0 0 40 40` |
| Цвета подложек | `#1A1A1A`, `#F6F6F6`, фирменный градиент |
| Паддинг подложки | 80px по бокам, контент до 1750px |
| Заголовок секции | **по центру**, 48px, вес **600**, на 110px от верха подложки |
| Акцент заголовка | вторая строка `#22D48D` |
| Карточки | радиус **20px**, gap **20px**, сетка 3×570 |
| Чипы | радиус 10px |
| Кнопки | pill 100px: градиент + тёмный текст, либо `#1A1A1A` + белый |
| Шрифт | Onest, веса 400–800, `letter-spacing: 0` |
| Текст | основной `#1A1A1A`, вторичный `#56778F`, тихий `#909090` |
| Градиент | `linear-gradient(0.125turn, #22D48D 0%, #DEFF3F 100%)` |

Ритм подложек на странице: тёмный герой → градиентная миссия → светлые истории →
тёмное взаимодействие с государством → **сращённая светлая поверхность**
(партнёры + награды) → тёмные письма → светлые документы → градиентный CTA →
тёмный футер со скруглением только сверху.

Геометрия проверена в Chromium и совпадает с сайтом: 1920→подложка 1910 при
зазоре 5px и радиусе 40px, 1440→1430, 768→758, 360→350 при радиусе 20px.
На всех ширинах нет горизонтальной прокрутки и содержимое не выходит за карточки.
Заглушки контента помечены в разметке как `TODO`.

Важно про доступность: акцент заголовка `#22D48D` на светлой подложке даёт
контраст 1.79:1 — ниже порога WCAG даже для крупного текста. Оставлено как
в фирстиле; переменная `--accent-on-light` позволяет поменять это одной правкой.

## Как выбрать

| Задача | Скилл |
|---|---|
| Завод, подряд, оборудование, логистика, B2B-поставки | `industrial-landing` |
| Фестиваль, конференция, премия, спецпроект, лонгрид | `festival-landing` |
| Страница в фирменном стиле Prodamus | `pages/social-responsibility` как основа |

Скиллы подхватываются автоматически по формулировке задачи. Страница Prodamus —
готовый артефакт, а не скилл: её берут как основу для других страниц бренда.
