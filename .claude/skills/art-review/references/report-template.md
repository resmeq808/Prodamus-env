# Шаблон отчёта

Сохранять в `review/REVIEW.md`. Пользователю в чат — только вердикт, таблицу оценок, блокеры и топ-3; ссылка на полный отчёт.

```markdown
# Ревью: <название страницы>

**Бриф:** <что продаём, кому, главное действие — 1–2 предложения>
**Эталон:** <мудборд / референсы / скилл, с чем сравнивали>
**Смотрели:** 1440, 768, 390 · <дата>

## Вердикт: <Показывать / Показывать после правок / Переделать>

<2–3 предложения: общее впечатление, главная сила, главная слабость.>

## Первые 5 секунд

<Что понятно, куда смотрит глаз, куда нажать, на что похоже.>

## Оценки

| Ось | Балл | Коротко |
|---|---|---|
| Идея и уместность | 8 | … |
| Первый экран | 7 | … |
| Композиция и сетка | … | … |
| Типографика | … | … |
| Изображения | … | … |
| Цвет | … | … |
| Ритм и воздух | … | … |
| Детали | … | … |
| Тексты и смысл | … | … |
| Коммерческая логика | … | … |
| **Среднее** | **…** | |

## Три решения с наибольшим эффектом

1. **<Что сделать>** — <почему это поднимет страницу сильнее всего>.
2. …
3. …

## Находки

### Блокеры
1. **<Где: секция · ширина · элемент>** — <что не так>. *Почему:* <принцип>. *Правка:* <конкретно, с цифрами или готовым текстом>.

### Важно
…

### Полировка
…

## Не трогать

- <Удачное решение и почему оно работает.>
- …

## Что исправлено после ревью
<Заполняется, если правки вносились: номер находки → что сделано → проверено на скриншоте.>
```

Правила:
- Нумерация находок сквозная (Б1, В1, П1 — блокер, важно, полировка), чтобы на них можно было ссылаться.
- Каждая находка — одна проблема, одна правка.
- Правка текста — готовой формулировкой в «ёлочках», правка вёрстки — значениями (`letter-spacing: -.025em`, `отступ 96 → 64px`, `сдвинуть на 2 колонки вправо`).
- Не больше 25 находок; мелочи группировать.
