# Пресеты: десять готовых ДНК

Каждый пресет — связная система из `variation.md`, собранная по конкретным референсам доски. Это стартовая точка, а не шаблон: возьми пресет и замени 2–3 оси под бриф. Два сайта подряд на одном пресете без замен — калька.

Для каждого: характер, ДНК, шрифты, палитра, фирменные ходы, чего **не** делать и ключевой CSS.

---

## P1. Кинематограф
**Референсы:** Creative Digital Agency, Stodio, Tenebra. **Кому:** финтех, платежи, агентства, спорт, мода.
**ДНК:** G1 · H1 · N1 · B1 · T1 (+T2 для одного слоя) · C1 · I1 · R2 · M1 · S1 S6 S14 S5 · F1 · D1
**Шрифты:** Inter Tight + Sofia Sans Extra Condensed. **Палитра:** #0b0b0c, лист #efeee9, акцент с кадра.
**Фирменное:** кадр в панели со скримом, лесенка, цифры-выноски, светлый лист на тёмной странице.
**Не делать:** бенто с мини-интерфейсами, плашки-уведомления.
**Код:** `assets/starter.html` (Selix) и приёмы 1–18 `art-direction.md`.

## P2. Швейцарская сетка
**Референсы:** Katie Hunter, Liam Bennett, Forty Seven. **Кому:** эксперты, портфолио, фотографы, архитекторы, консалтинг.
**ДНК:** G2 · H2 · N2 · B2 · T6 · C2/C3 · I2 · R4 · M2 · S15 S10 S14 S19 · F2 · D8
**Шрифты:** Golos Text 400/700 или Inter Tight 500/800. **Палитра:** #f4f3ef бумага, #0e0e0e текст, один цвет-знак (синий, красный) в 2–3 точках.
**Фирменное:** много пустых колонок; жирный капс плотным блоком в правой половине; тонкие линейки на всю ширину; подписи в скобках; фото маленькие и ч/б; подвал — контакты гигантским текстом.
**Не делать:** скруглённые панели, тени, стекло, таблетки, градиенты.
```css
.sw { display: grid; grid-template-columns: repeat(12, minmax(0,1fr)); column-gap: 1.25rem; border-top: 1px solid var(--ink); padding-block: 1rem 6rem; }
.sw__label { grid-column: 1 / 3; font: 500 .75rem/1.3 var(--font); text-transform: uppercase; }   /* [ ABOUT ] */
.sw__big   { grid-column: 7 / -1; font: 800 clamp(2.6rem, 1rem + 5vw, 6.5rem)/.9 var(--font); letter-spacing: -.02em; text-transform: uppercase; }
.sw__text  { grid-column: 7 / 11; max-width: 44ch; }
.link { border-bottom: 1px solid currentColor; padding-bottom: .15em; } .link::after { content: " ↗"; }
```

## P3. Брутальный плакат
**Референсы:** HAUS® STUDIO, DRIVE, Stone for Art, «Visual Reflecting Meanings». **Кому:** события, мода, музыка, смелые бренды, медиа.
**ДНК:** G3/G1 · H3 · N4 · B3/B4 · T2 · C2 + C5 одним полем · I5/I2 · R0 · M4 · S4 S5 S18 S11 · F8/F2 · D5
**Шрифты:** Sofia Sans Extra Condensed 800 (заголовки капсом 12–25vw) + Inter. **Палитра:** чёрный, белый и одно кислотное или сигнальное поле (оранжевый #ff4a1c, лайм #c6ff3a, электрик #2b3cff).
**Фирменное:** два гигантских слова у противоположных краёв; лестница чисел; жёсткие прямоугольники; индексы `[ 1/2 ]`; ссылки в скобках; одна бегущая строка; инверсия блоков (белый/чёрный).
**Не делать:** скругления, стекло, мягкие тени, пастель.
```css
.poster { display: flex; justify-content: space-between; align-items: flex-start; font: 800 clamp(4rem, 1rem + 15vw, 18rem)/.78 var(--font-narrow); text-transform: uppercase; }
.stair { display: grid; grid-template-columns: repeat(4, 1fr); align-items: end; }
.stair > div:nth-child(1) { height: 30%; } .stair > div:nth-child(2) { height: 55%; } /* …каждая ступень выше */
.stair b { font: 800 clamp(6rem, 3rem + 12vw, 16rem)/.8 var(--font-narrow); }
.btn-br { font: 600 .8125rem/1 var(--font); text-transform: uppercase; } .btn-br::before { content: "[ "; } .btn-br::after { content: " ]"; }
```

## P4. Чертёж
**Референсы:** Elian Kent, METTECH, DegenKit. **Кому:** инженерия, медтех, приборы, ИИ, разработчики.
**ДНК:** G4 · H12/H3 · N3 · B6 · T4 · C6/C4 · I4 · R1 · M3 · S9 S10 S3 S8 · F6 · D8
**Шрифты:** JetBrains Mono / IBM Plex Mono + Inter Tight. **Палитра:** серебро #d9dadc → #9a9ca0 или монохром цвета бренда.
**Фирменное:** крестики на пересечениях сетки; выноски с тонкими линиями к деталям; нумерация [1] [2] [3]; координаты и версии; спецификация таблицей.
**Не делать:** рукописное, пастель, фото людей крупно.
```css
.bp { position: relative; border: 1px dashed var(--line); }
.bp::before, .bp::after { content: "+"; position: absolute; font: 400 14px/1 var(--font-mono); color: var(--ink-3); }
.bp::before { left: -5px; top: -8px; } .bp::after { right: -5px; bottom: -8px; }
.callout { position: absolute; padding-left: 5rem; } .callout::before { content: ""; position: absolute; left: 0; top: .6em; width: 4.5rem; height: 1px; background: currentColor; }
```

## P5. Скрапбук
**Референсы:** Soul Waves, «artists.», Sharing Your Vision. **Кому:** музыка, культура, фестивали, кафе, детское, креативные сообщества.
**ДНК:** G7 · H9 · N4/N2 · B7 · T2 или T5 + моно · C3 + C5 · I6 · R0/R3 смешанно · M4 · S11 S7 S20 · F8 · D5
**Шрифты:** Sofia Sans Extra Condensed / Oswald + IBM Plex Mono. **Палитра:** кремовая бумага #f1ead9, один насыщенный цвет (синий #3a4fb8, красный #d8352a).
**Фирменное:** повёрнутые фото с тенью и «скотчем»; огромный цветной заголовок; моно-подписи; цитата на цветном поле; стикеры.
**Не делать:** ровные ряды карточек, стекло.

## P6. Бенто-модули
**Референсы:** Sharing Your Vision, «What We Do Best», Yolo, Nabulé. **Кому:** SaaS, агентства, приложения, продукты со множеством функций.
**ДНК:** G10 · H8/H5 · N6 · B1/B8 · T1 или T5 · C5/C2 · I8 · R3 · M6 · S13 S12 S14 S16 · F3 · D3
**Шрифты:** Manrope / Onest / Unbounded для цифр. **Палитра:** белый + насыщенный бренд-цвет полями, 3D-объекты в том же цвете.
**Фирменное:** плитки разной площади; 3D-предметы; кольцо-схема; стек карточек при прокрутке; цветной подвал-призыв.
**Не делать:** плитки с имитацией интерфейса, одинаковые плитки.

## P7. Галерея / журнал
**Референсы:** Studio Aton, Dulcedo, Nabulé, Shatsillo. **Кому:** отели, мода, ювелирка, beauty, агентства талантов, эксперты премиум.
**ДНК:** G6 · H4 · N7 · B2/B4 · T3 · C3/C2 · I3 · R0/R2 · M6/M4 · S1 S7 S3 S19 · F7/F4 · D1
**Шрифты:** Cormorant Garamond / Playfair Display / Prata (курсив как акцент) + Manrope / Jost. **Палитра:** тёплая или холодная бумага, тёмный текст, акцент — металл/терракота/глубокий синий.
**Фирменное:** симметрия; мозаика фото в hero; курсивное слово в гротесковой строке; центральные заголовки; горизонтальная лента номеров/коллекций; подвал-фото.
**Не делать:** лесенку, капсу-колонтитулы, таблетки с кругом.
```css
.mosaic { display: grid; grid-template-columns: 1.2fr 1fr 1fr 1.2fr; grid-template-rows: 1fr 1fr; gap: 6px; height: 100svh; }
.mosaic img:nth-child(1) { grid-row: 1 / 3; } .mosaic img:nth-child(4) { grid-row: 1 / 3; }
.serif-mix em { font-family: var(--font-serif); font-style: italic; font-weight: 400; }
```

## Как отличить пресеты с первого взгляда

| Пресет | Узнаётся по |
|---|---|
| P1 | тёмная страница, кадр в панели, лесенка, таблетка + оранжевый круг |
| P2 | бумага, линейки, пустые колонки, жирный капс справа |
| P3 | чёрно-белый, узкий капс на весь экран, прямые углы, скобки |
| P4 | крестики, моно, выноски, серебро |
| P5 | крем, повёрнутые вырезки, цветной гигантский заголовок |
| P6 | плитки, 3D, круги, цветные поля |
| P7 | симметрия, антиква с курсивом, мозаика фото |
| P8 | предмет в центре, слова вокруг |
| P9 | карточки-разделы, часы, данные |
| P10 | цветная рамка вокруг сайта |
