# Детали: из чего складывается «аккуратно»

Дорогой сайт отличается от шаблона не приёмами, а сотней мелочей, которые по отдельности никто не замечает. Вместе они дают ощущение, что страницу делали руками. Здесь всё, что проверяется перед сдачей, с готовым CSS.

---

## Типографика

### 1. Отрицательный трекинг на крупном кегле

В SaaS-выборке поджаты 3 из 4 заголовков hero (медиана −0.02em, у четверти — −0.03em и сильнее). Чем больше кегль, тем сильнее:

| Кегль | letter-spacing |
|---|---|
| 14–18px текст | `0` … `-0.005em` |
| 20–32px подзаголовки | `-0.01em` … `-0.015em` |
| 40–64px заголовки секций | `-0.02em` … `-0.03em` |
| 72px и больше, hero | `-0.03em` … `-0.045em` |
| 100–150px, гигант лесенкой | `-0.045em` (кириллица) … `-0.06em` (латиница) |

Ниже `-0.05em` буквы слипаются. Кириллица шире латиницы, поэтому поджимайте её на 0.005em меньше.

Мелкий текст на 11–13px, наоборот, разгоняют: `+0.01em`. Капс разгоняют всегда: `+0.04em` … `+0.08em`.

### 2. Межстрочный интервал обратно пропорционален кеглю

```
hero 64–96px    line-height 0.95–1.05
H2   40–56px    1.05–1.15
H3   22–28px    1.2–1.3
текст 16–18px   1.5–1.6
мелкий 13–14px  1.45–1.5
```

Интерлиньяж 1.5 на заголовке 72px — самый частый признак сайта без дизайнера.

### 3. Переносы и висячие строки

```css
h1, h2, h3, .lead { text-wrap: balance; }       /* ровные строки заголовков */
p, li, figcaption { text-wrap: pretty; }        /* без одинокого слова в последней строке */
```

Для кириллицы добавьте неразрывные пробелы после предлогов и союзов в 1–2 буквы: `в&nbsp;работе`, `и&nbsp;команда`. Короткое тире между числами без пробелов: `2–4`, а тире в предложении отбивайте неразрывным пробелом: `сайт&nbsp;— это`.

### 4. Цифры

```css
.num, .price, table, .stat { font-variant-numeric: tabular-nums; }  /* колонки не пляшут */
.stat-big { font-feature-settings: "ss01", "cv11"; }               /* альтернативные глифы, если у шрифта есть */
```

Большие числа набирайте с тонкой шпацией: `12 400`, не `12400` и не `12,400` в русском тексте. Валюта после числа через неразрывный пробел: `4 900&nbsp;₽`.

### 5. Кавычки, тире, многоточие

«Ёлочки» в русском тексте, “лапки” внутри ёлочек и в английском. Длинное тире `—` в предложении, короткое `–` в диапазонах, дефис `-` только в словах. Многоточие — один символ `…`.

### 6. Оптическая компенсация

- Заголовок крупнее 64px визуально отходит от левого края из-за боковых полей первой буквы. Сдвиньте его на `margin-left: -0.04em`, чтобы он встал на одну линию с текстом ниже.
- Иконка в кнопке на 1–2px выше центра выглядит опущенной. Проверяйте глазами, а не по `align-items`.
- Треугольник «play» визуально смещён влево — сдвиньте его на 8–10% ширины вправо.

## Цвет

### 7. Чёрный — не #000

Основной текст почти всегда чуть светлее и чуть тоньше чистого чёрного: `#0a0a0a` … `#1d1d1f`. На тёмной земле текст — не `#fff`, а `#f5f5f7` … `#ededed`.

### 8. Вторичный текст — прозрачностью, а не отдельным серым

```css
--ink: #111113;
--ink-2: color-mix(in oklab, var(--ink) 64%, transparent);  /* описания */
--ink-3: color-mix(in oklab, var(--ink) 44%, transparent);  /* подписи, мета */
```

Так вторичный текст автоматически подхватывает оттенок фона на любой секции. Контраст `--ink-3` на белом проверяйте: ниже 4.5:1 он допустим только для текста крупнее 18px.

### 9. Линии — полупрозрачные

```css
--line: color-mix(in oklab, var(--ink) 10%, transparent);
```

1px, никогда не 2px. На тёмной земле — `rgba(255,255,255,.08….12)`.

### 10. Выделение, курсор, скроллбар

То, что браузер рисует сам, тоже часть дизайна. Проверяется за 10 секунд и почти всегда забыто:

```css
::selection { background: color-mix(in oklab, var(--accent) 28%, transparent); color: inherit; }
:root { accent-color: var(--accent); caret-color: var(--accent); color-scheme: light; }
html { scrollbar-color: color-mix(in oklab, var(--ink) 25%, transparent) transparent; }
```

## Ссылки, кнопки, фокус

### 11. Подчёркивание

```css
a { text-underline-offset: .22em; text-decoration-thickness: 1px; text-decoration-color: color-mix(in oklab, currentColor 35%, transparent); }
a:hover { text-decoration-color: currentColor; }
```

### 12. Кнопка — это пять состояний

default, hover, active, focus-visible, disabled. Hover — сдвиг яркости на 6–10% или смена фона, `transition: 160ms`. Active — `transform: translateY(1px)` или `scale(.98)`. Фокус — кольцо со смещением:

```css
:focus-visible { outline: 2px solid var(--accent); outline-offset: 3px; border-radius: inherit; }
```

### 13. Стрелка в кнопке двигается, кнопка — нет

Если у кнопки есть иконка-стрелка, на hover сдвигается только она, на 2–3px. Вся кнопка «прыгать» не должна.

### 14. Высоты кнопок кратны сетке

40 / 44 / 48 / 56px. Внутренние поля по горизонтали — примерно высота × 0.45. Две кнопки рядом всегда одной высоты.

## Изображения

### 15. Картинки не прыгают

У каждого `<img>` — `width`, `height` или `aspect-ratio`. Все кадры одного ряда — одного соотношения сторон.

```css
img { display: block; max-width: 100%; height: auto; }
.media { aspect-ratio: 4 / 3; object-fit: cover; background: var(--surface-2); }
```

### 16. Скругление картинки = скругление карточки минус отступ

Если карточка со скруглением 20px и паддингом 8px, картинка внутри — 12px. Одинаковые радиусы у вложенных элементов выглядят кривыми.

```css
.card { --r: 20px; --pad: 8px; border-radius: var(--r); padding: var(--pad); }
.card img { border-radius: calc(var(--r) - var(--pad)); }
```

### 17. Тонкая обводка на светлых фото

Белый предмет на белой карточке теряет границу. Добавьте внутреннюю линию, которую не видно, но которая держит край:

```css
.shot { box-shadow: inset 0 0 0 1px color-mix(in oklab, var(--ink) 6%, transparent); }
```

### 18. Скриншоты интерфейса

Скриншоты продукта — всегда настоящие, в ретине, с лёгкой тенью и рамкой. Не рисуйте интерфейс дивами.

```css
.ui-shot { border-radius: 14px; box-shadow: 0 0 0 1px rgba(0,0,0,.06), 0 24px 48px -12px rgba(16,24,40,.18); }
```

## Тени и глубина

### 19. Тень — многослойная и тонированная

Одна серая тень `0 4px 12px rgba(0,0,0,.1)` — признак шаблона. Дорогая тень — это 2–3 слоя: контактный, средний и широкий мягкий, подкрашенные в цвет фона.

```css
--shadow-1: 0 1px 2px rgba(16,24,40,.06), 0 1px 1px rgba(16,24,40,.04);
--shadow-2: 0 1px 2px rgba(16,24,40,.05), 0 8px 24px -6px rgba(16,24,40,.12);
--shadow-3: 0 2px 4px rgba(16,24,40,.04), 0 24px 64px -16px rgba(16,24,40,.22);
```

На странице используется максимум два уровня тени. Большинство поверхностей держатся на смене фона и линии, а не на тени.

## Движение

### 20. Один поставленный момент

Одно заметное движение на страницу: появление hero, раскрытие продукта при скролле, счётчик. Остальное — мгновенно или микро (hover 160ms).

```css
--ease-out: cubic-bezier(.16, 1, .3, 1);
--dur-1: 160ms;  /* hover, цвет */
--dur-2: 320ms;  /* раскрытие, аккордеон */
--dur-3: 700ms;  /* появление hero */

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: 1ms !important; transition-duration: 1ms !important; scroll-behavior: auto !important; }
}
```

### 21. Шапка при скролле

Липкая шапка становится полупрозрачной с размытием, а не просто белой с тенью:

```css
.nav { position: sticky; top: 0; backdrop-filter: saturate(1.6) blur(14px); background: color-mix(in oklab, var(--bg) 78%, transparent); border-bottom: 1px solid transparent; transition: border-color var(--dur-1); }
.nav.is-scrolled { border-bottom-color: var(--line); }
```

## Мелочи, которые проверяют последними

22. Favicon, `theme-color`, `og:image` 1200×630 — есть.
23. Кнопки не переносятся на две строки ни на одной ширине.
24. У телефонов `href="tel:"`, у почты `mailto:`.
25. Якорные ссылки не прячут заголовок под липкой шапкой: `scroll-margin-top: calc(var(--nav-h) + 24px)`.
26. На мобильном тап-зона каждого интерактивного элемента не меньше 44×44px, даже если видимая иконка 20px.
27. Горизонтального скролла нет ни на одной ширине от 320px: проверьте `document.documentElement.scrollWidth === innerWidth`.
28. Пустые состояния, ошибки формы и успех отправки нарисованы, а не оставлены браузеру.
29. Копирайт в подвале — текущий год.
30. Ни одного `lorem ipsum`, «Иван Иванов», «Компания 1», `example.com` в финальной версии.
