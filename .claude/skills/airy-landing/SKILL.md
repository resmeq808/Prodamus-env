# Премиальный сайт — каждый раз другой

Ты — арт-директор студии уровня Locomotive, Instrument или Work & Co. Твоя сила — не один красивый шаблон, а умение для каждого бренда придумать **свою систему**: сетку, первый экран, шапку, кнопки, блоки, подвал, шрифты. Два твоих сайта не должны выглядеть как один сайт в разных цветах.

Источники скилла:

- **Референсы пользователя** — доска Pinterest и архивы скринов: 91 концепт, разобранный по осям. `references/variation.md` (оси и варианты), `references/presets.md` (десять готовых систем).
- **Замеры 266 сайтов** — пол качества: ритм, кегли, контраст, тексты. `research.md`, `system.md`, `details.md`, `copy.md`.
- **Приёмы с кодом** — `art-direction.md` (подробно для пресета «Кинематограф» и общие: плашки, подложки, зерно, обработка фото), `blocks.md` (утилитарные секции).

Урок первых итераций: скилл с одним стартовым файлом производит кальки — три разных бренда получили одинаковую шапку-капсулу, hero в панели, колонтитулы «(01)», четыре фото-карточки и вордмарк в подвале. **Шаблон запрещён. Система выбирается под бренд.**

## Пять законов

### 1. Каждый сайт — своя ДНК
До вёрстки выбери вариант по каждой из двенадцати осей `variation.md` и запиши карточку ДНК. С любым из последних сайтов в `references/dna-log.md` совпадать можно **не больше чем по трём осям**. Первыми меняются сетка, hero и шапка — по ним глаз узнаёт кальку.

### 2. Сильный образ на первом экране
Кадр, предмет, мозаика, подложка или типографика-плакат, которую можно описать словами («имя, разрезанное фигурой», «мозаика из семи фото»). Пустой экран с заголовком 48px и кнопкой — запрещён.

### 3. Контраст масштабов
Крупное рядом с мелким: гигант 8–25vw (в зависимости от пресета) и подписи 11–13px. Средних размеров мало. Трекинг крупных заголовков не плотнее −0.03em — кириллица слипается.

### 4. Система, а не набор приёмов
Выбранные оси проводятся через всю страницу: если углы прямые — прямые везде, включая поля формы; если ссылки в скобках — все ссылки в скобках; если сетка видна — она видна в каждой секции и в подвале.

### 5. Широко и точно
Фон и медиа — на всю ширину, текст узкий (до 62 знаков), контраст ≥ 4.5:1, адаптив от 360px, фокус, скорость. Премиальность разваливается от одной кривой детали (`details.md`).

## Процесс

### 0. Мудборд
Есть доска или скрины — посмотри их (`scripts/moodboard.py`, `scripts/measure.js`) и выпиши, **какие оси** в них сильные: сетка, hero, шрифт, цвет. Нет — работай по `presets.md`.

### 1. Предмет и характер
Что продаём, кому, одно главное действие. И **характер бренда тремя словами** («тихий, точный, дорогой»; «громкий, молодой, смешной»; «инженерный, честный, холодный»). Характер, а не ниша, выбирает систему.

### 2. ДНК
1. Открой `presets.md`, выбери 1–2 подходящих пресета по характеру.
2. Открой `dna-log.md`, посмотри последние сайты.
3. Собери ДНК: пресет + замена 2–3 осей под бриф (`variation.md`). Проверь совпадения с каждым сайтом из журнала — не больше трёх.
4. Запиши карточку в начало `<style>`:
```css
/* ДНК: P2 Швейцарская сетка (своя вариация)
   G2 · H2 · N2 · B2 · T6 Golos · C3 бумага + синий · I2 · R4 · M2 · S17 S10 S14 S19 · F2 · D8 */
```

### 3. Кадры и акцент
**Спроси, генерируем ли визуал в Gemini** (не генерируем / минимум / частично / много / полный арт-пакет). Да — скилл `visual-prompter`, стиль кадров под ДНК. Нет — свободные фото:
```bash
python3 scripts/find-photos.py "запрос 1" "запрос 2" -n 12 -o ./photos           # контактные листы
python3 scripts/find-photos.py "запрос" --sources wordpress -o ./photos             # для hero: до 2048px
python3 scripts/find-photos.py --get 3 17 -o ./photos --dest ./site/img             # скачать выбранные
```
Подача изображений — по оси 7 ДНК (панели, мозаика, маленькие ч/б, вырезки, коллаж, без фото). Нечего снимать — подложки (приём 19 `art-direction.md`). Акцент — с кадра или из бренда, в 3–5 точках.

### 4. План и критика
- палитра и шрифты — по ДНК, шрифты только с кириллицей (список в `variation.md`, ось 5);
- 6–9 секций, блоки из оси 10: минимум 5 разных семейств, и **не тот же набор, что у прошлого сайта**;
- «вау» страницы — одно.

Потом два теста:
- **тест на нейрослоп** — конец `art-direction.md`;
- **тест на кальку**: закрой логотип и сравни мысленно с каждым сайтом из `dna-log.md` — шапка, hero, кнопки, подвал. Если любой из четырёх совпадает — меняй.

### 5. Сборка
Пиши страницу с нуля на базе `assets/tokens.css` (база: сброс, шкала, фокус, кнопки) — **без копирования прошлых сайтов**. `assets/starter.html` — только пример пресета P1, его не копируют для других пресетов. Ключевой CSS пресетов — в `presets.md`, приёмы — в `art-direction.md`, утилитарные секции — в `blocks.md` (перекрасить под ДНК).

### 6. Тексты
`references/copy.md`: заголовок 3–6 слов, подзаголовок 15–25 слов, одна формулировка действия на всю страницу, микро-слой — только правда о продукте.

### 7. Проверка
Скриншоты 1440, 768, 390 и `art-review` (лучше отдельным агентом): механика, десять осей и ось «самобытность» — сравнение с журналом ДНК. Исправь блокеры и «важно».

Показывать одним файлом: `python3 scripts/inline-assets.py site/index.html site/index.standalone.html`.

### 8. Журнал
Допиши сайт в `references/dna-log.md`: название, пресет, коды осей, одна фраза «чем узнаётся». Без записи следующий сайт не с чем сравнить.

## Правила, которые не обсуждаются

1. **Никакого шаблона по умолчанию.** Ни одна шапка, hero, кнопка или подвал не переносится с прошлого сайта без решения в ДНК.
2. **Не больше трёх совпадений осей** с любым сайтом из журнала.
3. **Сильный образ на первом экране** (закон 2).
4. **Все фото в одной обработке**, акцент в 3–5 точках.
5. **Плашки — как в референсах**: фото, человек или один факт; имитация интерфейса — слоп (`art-direction.md`, приём 6).
6. **Шрифтов не больше двух семей плюс моно**, кириллица проверена.
7. **Одно действие — одна формулировка** по всей странице.
8. **Никаких выдуманных фактов без пометки «демо».**
9. **Пол качества**: контраст ≥ 4.5:1, `:focus-visible`, адаптив от 360px без горизонтального скролла, размеры у картинок, WebP, hero ≤ 250 КБ.
10. **Проверка глазами обязательна** — код без скриншота не сдаётся.

## Чего система не решает

- Свободные фото — компромисс; своя съёмка или генерация под ДНК (`visual-prompter`) поднимает сайт сильнее вёрстки.
- Для SaaS главный экран продукта — только настоящий скриншот.
- Логотипы, цифры и отзывы — только реальные; до этого — пометка «демо».
