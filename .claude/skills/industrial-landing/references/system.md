## Цвет

### Формула

```
ЗЕМЛЯ-СВЕТ   белый или почти белый   #ffffff · #fcfcfc · #f1f1f1
ЗЕМЛЯ-ТЁМНАЯ графит, не чёрный        #1c1c1c · #232c35 · #262e28 · #061e25
АКЦЕНТ       один, деловой            3–8% площади
ТЕКСТ-МУТ    серый для описаний       #6b6b6d · #747474 · #949595
ЛИНИЯ        1px                      rgba(ink, .12)
```

Страница строится чередованием светлой и тёмной земли. Акцент **никогда** не становится землёй целой секции — он на кнопках, на одной плитке из шести, на номерах, на двух словах заголовка.

### Готовые палитры

Сняты с разобранных сайтов. Тёмная земля почти нигде не чистый `#000` — она с подмесом того же тона, что и акцент.

```css
/* Индиго — подряд, инженерия (Propoly, 81 ♥) */
--ground:#ffffff; --ground-dark:#1a1c2e; --accent:#33396a; --accent-hover:#29388a; --muted:#6b6b6d;

/* Синий — оборудование, ИТ-инфраструктура (Дата-Поинт, 189 ♥) */
--ground:#ffffff; --ground-dark:#1c1b1e; --accent:#174eb5; --accent-hover:#3a69c0; --muted:#9d9d9e;

/* Красный — металл, логистика (Ижора · Главный Путь · Woodpecker) */
--ground:#fcfcfc; --ground-dark:#0e0e0e; --accent:#e91f2f; --accent-hover:#cb0000; --muted:#949595;

/* Хвойный — строительство, дерево (EasyBuild, 217 ♥) */
--ground:#ffffff; --ground-dark:#262e28; --accent:#304e42; --accent-hover:#3c5b50; --muted:#656565;

/* Охра — фасады, отделка (Siding Moldova, 82 ♥) */
--ground:#ffffff; --ground-dark:#131313; --accent:#cf960a; --accent-hover:#e0a617; --muted:#6c6c6c;

/* Морская бирюза — автокомпоненты, техника (Monaer, 79 ♥) */
--ground:#ffffff; --ground-dark:#061e25; --accent:#43999f; --accent-hover:#1f5260; --muted:#5a777f;

/* Сине-графит — камень, кирпич (Brick Art, 65 ♥) */
--ground:#ffffff; --ground-dark:#232c35; --accent:#2e3a46; --accent-hover:#333e48; --muted:#9ca5ab;

/* Тёплый камень — природный материал (Irstone, 63 ♥) */
--ground:#f5f3f1; --ground-dark:#2b2c2c; --accent:#8a6a4a; --paper:#e4dbd0; --muted:#747474;

/* Navy + красный — международная логистика (Курс) */
--ground:#ffffff; --ground-dark:#1f265b; --accent:#eb1f44; --accent-hover:#cb0f34; --muted:#6d7997;
```

### Как выбрать акцент

Берите цвет **от материала или отрасли**, а не «любимый корпоративный синий»:

- металл, огонь, скорость → красный;
- вода, воздух, точность, ИТ → синий, индиго, бирюза;
- дерево, земля, экология → хвойный, оливковый;
- камень, песок, фасад → охра, тёплый серо-коричневый;
- премиум и сдержанность → графит с лёгким подмесом синего, вообще без цветного акцента (Blackwood).

У Irstone палитра буквально снята с камня — бежевый `#e4dbd0` рядом с графитом. Это самый сильный ход жанра: **палитра, выведенная из продукта, выглядит дороже любой модной**.

### Светлый акцент — исключение

Единственный кислотный акцент в подборке — лайм `#c5f79e` у Airdog. Работает потому, что земля тёмно-графитовая `#222f30`, а лайма меньше 5%. На светлой земле такой акцент разваливает страницу.

## Типографика

### Одна гарнитура на весь сайт

В 14 сайтах из 16 — **один нейтральный гротеск** во всех ролях. Различие делается кеглем, весом и цветом, а не второй гарнитурой. Это принципиально: жанр требует, чтобы шрифт не мешал читать спецификацию.

**Бесплатные с кириллицей (проверены по субсетам Google Fonts):**

`Golos Text` · `Onest` · `Manrope` · `Inter` · `Inter Tight` — любая закрывает весь сайт.
Моно для мета и таблиц: `Roboto Mono` · `JetBrains Mono` · `IBM Plex Mono`.
Характерный техно-гротеск, если нужен голос (как Tektur у Ижоры): `Tektur` · `Unbounded`.

Коммерческие, которые стоят на разобранных сайтах: Involve, TT Firs Neue, Halvar Breitschrift, Suisse Intl, SF Pro Display, LoftStyle. Заменяются на Golos Text / Manrope без потери жанра.

### Шкала

Сняты с разобранных сайтов, десктоп:

```css
--fs-hero:    clamp(1.5rem, 7vw, 3.5rem);    /* 24–56px, вес 400–600     */
--fs-h2:      clamp(1.5rem, 2.2vw, 2.25rem); /* 24–36px                  */
--fs-h3:      1.25rem;                        /* 20px                     */
--fs-num:     clamp(2rem, 3.6vw, 3.5rem);    /* 40–56px, числа           */
--fs-num-xl:  clamp(2.5rem, 5vw, 4.25rem);   /* 48–68px, крупные числа   */
--fs-lead:    1.125rem;                       /* 18px, подзаголовок       */
--fs-body:    0.9375rem;                      /* 15px — рабочий размер    */
--fs-small:   0.8125rem;                      /* 13px, описания в карточках */
--fs-meta:    0.6875rem;                      /* 11px, мета-подписи       */

--lh-head: 1.2;    /* заголовки и числа */
--lh-mid:  1.35;   /* подзаголовки      */
--lh-body: 1.55;   /* абзацы            */
```

Реальные частоты в разметке: 10–12px (мета) — самый частый размер на странице, 14–16px (текст), 18–25px (подзаголовки и h3), 30–45px (h1/h2), 48–68px (числа).

**Нижняя граница `clamp()` подбирается по самому длинному слову.** Русские отраслевые
термины — «металлоконструкции», «энергоэффективность», «теплоизоляция», «комплектующие» —
на 360px шире экрана при кегле 32px и рвут страницу горизонтальным скроллом. Проверьте
самое длинное слово заголовка на 360px и опустите нижнюю границу до кегля, при котором
оно помещается в строку. Страховка в дополнение к этому, а не вместо:

```css
.h2, .h3, .hero__title { hyphens: auto; overflow-wrap: anywhere; }
```

`hyphens: auto` переносит по слогам там, где в браузере есть русский словарь; `overflow-wrap: anywhere`
ломает слово в произвольном месте — некрасиво, но лучше горизонтального скролла.

Вторая частая причина переполнения — **грид-колонка `1fr` вместо `minmax(0, 1fr)`**.
Трек `1fr` не может стать уже своего содержимого, поэтому длинное слово или широкое число
распирают всю сетку. В мобильных раскладках всегда `minmax(0, 1fr)`.

### Веса

```
400  весь текст и большинство заголовков
500  подзаголовки, названия карточек, числа
600  заголовок первого экрана, кнопки
700  максимум; в жанре почти не нужен
```

**Вес 800–900 не используется.** Ни на одном из 16 сайтов.

### Мета-подписи

Самая узнаваемая деталь жанра. Форматы, встреченные в разборе:

```
• направления          точка-маркер акцентного цвета
[ 4 преимущества ]     квадратные скобки
01 — о компании        номер с длинным тире
02/06                  позиция в серии
ПРОБЛЕМА               просто uppercase
```

```css
.meta { font-size: var(--fs-meta); text-transform: uppercase; letter-spacing: .08em; color: var(--muted); }
.meta--dot::before { content: "•"; color: var(--accent); margin-inline-end: .5em; }
```

### Приглушённая вторая строка

Приём EasyBuild (217 ♥) и TrustPay (141 ♥): часть заголовка того же кегля — светло-серая.

```html
<h2 class="h2">Строим будто для себя.<br><span class="h2__mute">А по-другому — не умеем.</span></h2>
```
```css
.h2__mute { color: color-mix(in oklab, currentColor 32%, transparent); }
```

Даёт объём заголовку, не добавляя ни цвета, ни гарнитуры. Работает и для смысловых уточнений: «…помогающий бизнесу *безопасно взаимодействовать* с цифровыми активами».

### Акцент на двух словах

Приём Siding Moldova и Ижоры: в заголовке цветом выделены **ровно два слова** — предмет.

```html
<h1 class="hero__title">Установка <span class="accent">винилового сайдинга</span> в Молдове под ключ</h1>
```

Больше двух слов — заголовок начинает мигать.

## Сетка

```css
--container: 1200px;        /* у всех 16 сайтов ровно столько */
--container-wide: 1440px;   /* полноширинные фото-секции      */
--gutter: clamp(1rem, 3vw, 2.5rem);
```

12 колонок, `gap` 20–24px. Рабочие раскладки:

| Блок | Сетка |
|---|---|
| Цифры | `repeat(auto-fit, minmax(240px,1fr))`, 4 или 6 плиток |
| Направления | 2 колонки на десктопе, 1 на планшете |
| Каталог | `repeat(auto-fill, minmax(230px,1fr))` |
| Этапы | 4 колонки, на мобильном — 2 |
| Преимущества-лента | 4 колонки с вертикальными разделителями |

Вертикальный ритм секций: `clamp(3.5rem, 6vw, 6.5rem)`. Плотнее, чем в имиджевых сайтах, — жанр не про воздух.

## Форма

### Радиусы

```css
--r-sm: 5px;    /* мелкие метки, инпуты           */
--r-md: 10px;   /* карточки — основной радиус     */
--r-lg: 20px;   /* секции-карточки, крупные блоки */
--r-pill: 999px;/* кнопки, теги-пилюли            */
```

Внутри одной страницы — **максимум два значения** плюс pill. Смешение 5 / 8 / 12 / 16 / 24 читается как несобранная система.

### Границы вместо теней

```css
.card { background: var(--surface); border: 1px solid var(--line); border-radius: var(--r-md); }
```

Серых `box-shadow` под карточками в разобранных сайтах нет. Глубина делается сменой фона и тонкой линией. Единственное допустимое исключение — липкая шапка при скролле.

### Кнопки

Пара «заливка + прозрачная с рамкой» — стандарт первого экрана.

```css
.btn {
  display: inline-flex; align-items: center; gap: .5em;
  padding: .95em 1.6em; border: 1px solid transparent; border-radius: var(--r-pill);
  font-size: var(--fs-body); font-weight: 600; line-height: 1; text-decoration: none;
  transition: background .2s, border-color .2s, color .2s;
}
.btn--primary { background: var(--accent); color: #fff; }
.btn--primary:hover { background: var(--accent-hover); }
.btn--ghost { background: transparent; color: inherit; border-color: currentColor; }
.btn--ghost:hover { background: color-mix(in oklab, currentColor 8%, transparent); }
.btn::after { content: "↗"; font-size: .9em; }        /* стрелка — в 12 сайтах из 16 */
.btn:focus-visible { outline: 3px solid var(--accent); outline-offset: 3px; }
```

Радиус кнопки бывает и прямоугольным (`--r-sm`) — тогда pill не используется нигде.

### Теги-пилюли

Мелкие метки поверх фото и в карточках (Propoly: «Устойчивость к износу», «Работа под нагрузкой»).

```css
.tag {
  display: inline-block; padding: .4em .8em; border-radius: var(--r-pill);
  background: rgba(255,255,255,.12); backdrop-filter: blur(6px);
  font-size: var(--fs-meta); color: #fff; white-space: nowrap;
}
```

### Иконки

- viewBox `0 0 24 24`, `fill="none"`, `stroke="currentColor"`, `stroke-width="1.5"`, `stroke-linecap="round"`;
- один набор на весь сайт;
- размер 20–24px в карточках, 32–40px в блоке этапов;
- часто в квадратной или круглой рамке `1px solid var(--line)` со стороной 40–48px.

Заливные, цветные и объёмные иконки жанру противопоказаны — они делают промышленный сайт похожим на детский сад. Исключение: 3D-рендеры самого изделия (Monaer), но это уже иллюстрация, а не иконка.
