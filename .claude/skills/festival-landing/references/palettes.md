# Палитры

Все значения сняты с разобранных сайтов: hex — из CSS и разметки, проценты — доля площади полностраничного скриншота после квантизации.

## Формула

```
ЗЕМЛЯ     один цвет, 40–98% площади   near-black или off-white
АКЦЕНТ    один цвет,  5–25% площади   кислотный, высокой насыщенности
ЧЕРНИЛА   текст на земле              контраст к земле ≥ 4.5:1
ШУМ       0–5% площади                второй цвет, только точечно
```

Всё. Четыре роли, не больше. Если в палитре появляется пятый цвет — это уже не решение, а отсутствие решения.

## Как собрать свою

1. **Землю выбирай первой.** Светлая земля — контент, много информации, дневное событие. Тёмная — атмосфера, премиальность, вечернее.
2. **Акцент бери на максимальной насыщенности** — в OKLCH это `C ≈ 0.2–0.3`. Приглушённый акцент читается как корпоративный и убивает всю затею.
3. **Проверь акцент на трёх задачах:** плашка с белым текстом · крупный заголовок на земле · тонкая линия 2px. Если хотя бы одна не читается — сдвигай светлоту, а не насыщенность.
4. **Чернила — не чистый `#000` на светлой земле.** `#0c0c0c`, `#131313`, `#28292b` выглядят дороже и мягче.
5. **Белый на тёмной земле — тоже не чистый.** `#fffcfc`, `#eeeded`, `#f6f7f1` снимают резь.

## Контраст

Кислотный акцент почти никогда не годится для основного текста. Допустимые применения:

- заливка плашки с чернильным текстом поверх — `#ffea00` + `#000`;
- заголовок от 48px на земле — там 3:1 достаточно по WCAG для крупного текста;
- линии, подчёркивания, маркеры, точки-разделители;
- **не** для абзаца 16px и **не** для мелких подписей.

Свечение (архетип B) не участвует в контрасте вообще: оно под текстом и размыто. Текст поверх свечения проверяй по самой светлой точке градиента.
