# Архитектура страницы

## Обязательный минимум для события

Порядок не случайный: он повторяет то, в каком порядке человек принимает решение.

```
1. HERO              что это, когда, где — и громкая вещь
2. ЧТО ЭТО           2–4 предложения, крупным кеглем
3. ЦИФРЫ             3–5 показателей кеглем заголовка
4. ПРОГРАММА         расписание / спикеры / активности
5. КОМУ              2–4 карточки аудитории
6. ДОКАЗАТЕЛЬСТВА    фото прошлого года, партнёры, отзывы
7. УСЛОВИЯ           билеты, цены, даты приёма заявок
8. ФИНАЛЬНЫЙ CTA     одно действие
9. ПОДВАЛ            контакты, соцсети, юр. строчка
```

Секции 3 и 6 опускаются, если событие первое. Всё остальное обязательно.

Для **нарратива** (архетип C) структура другая — сценарий, а не воронка: завязка → развитие по главам → кульминация → и только в самом конце, если нужно, одно действие.

---

## Правило чередования

**Каждая секция обязана отличаться от соседней** хотя бы по одному параметру: земля, плотность, ритм сетки. Пять одинаковых светлых секций подряд проваливают страницу независимо от того, что в них написано.

Рабочий ритм для события:

```
HERO        тёмный / фото          плотно
ЧТО ЭТО     светлый                очень просторно ← пауза
ЦИФРЫ       акцентный              плотно
ПРОГРАММА   светлый                плотно, сетка
КОМУ        светлый                просторно
ФОТО        тёмный / полноширинный плотно, без полей
УСЛОВИЯ     светлый                средне
CTA         акцентный              одна строка ← удар
ПОДВАЛ      тёмный                 мелко
```

Паузы (очень просторные секции) обязательны. На «Жизни после смерти» (440 ♥) пустого чёрного поля больше, чем контента, — и именно это делает страницу дорогой.

## Анатомия hero

Шесть элементов, порядок сверху вниз или по сетке:

1. **Мета-строка** — дата, город, формат. Моно, uppercase, мелко. Ставится над заголовком.
2. **Заголовок** — название события. От 7vw. Это громкая вещь либо её оправа.
3. **Наклейки** — 0–3 штуки, поверх заголовка или под ним.
4. **Подзаголовок** — одна строка, что это и для кого.
5. **Действие** — одна кнопка. Вторая допускается только как текстовая ссылка.
6. **Дата и место крупно** — если они не попали в мету. На «Сытом Бабре» «27-28 ИЮНЯ 2026» набрано кеглем заголовка.

Hero **не обязан** содержать изображение продукта, преимущества, логотипы клиентов и стрелку «листайте вниз».

```html
<header class="hero">
  <p class="meta">27–28 июня 2026 · Иркутск · вход свободный</p>
  <h1 class="display">БОЛЬШОЙ<br>ГАСТРОНОМИЧЕСКИЙ<br>ФЕСТИВАЛЬ</h1>
  <p class="sticker">300+ блюд</p>
  <p class="lead">Локальные, трендовые и экспериментальные блюда с байкальским духом.</p>
  <a class="btn" href="#tickets">Программа</a>
</header>
```

## Программа

Три рабочих формы, выбирается одна:

- **Таблица-список** — время, площадка, событие. Лучше всего для плотного расписания на 20+ пунктов (Слово-на-Дону). Строки-ссылки, разделители 1px, без карточек.
- **Карточки по дням** — 2–3 дня, вкладками. Для короткого события (Baltic Digital Days).
- **Табло** — крупные цифры с подписями, когда пунктов 4–6 (AffArts: «10 часов контента / 09 тем лекций / 08 спикеров»).

Спикеры: портрет, имя, одна строка регалий. Не больше. Ряд портретов в акцентных карточках (Plavno) читается лучше, чем сетка кружков.

## Доказательства

Самое ценное на фестивальном лендинге — **репортажные фото прошлого раза**. Разного размера, без единой обрезки, с наклейками поверх. Студийные стоковые снимки убивают доверие вернее, чем их отсутствие.

Партнёров — бенто-сеткой карточек (приём 11), не серой лентой логотипов.

## CTA

Одна секция, одно действие, акцентная земля, одна строка текста. Кнопка — сплошная заливка, без градиента, без тени, радиус либо 0, либо 999px.

```css
.btn { display: inline-flex; align-items: center; gap: .6em;
  padding: 1em 2em; border: 0; border-radius: 999px;
  background: var(--ink); color: var(--ground);
  font: 600 1rem/1 var(--font-text); text-decoration: none;
  transition: transform .2s, background .2s; }
.btn:hover { transform: translateY(-2px); }
.btn:focus-visible { outline: 3px solid var(--accent); outline-offset: 3px; }
```

Кнопка повторяется на странице 2–4 раза с одним и тем же текстом. Разные формулировки для одного действия («Купить билет», «Регистрация», «Участвовать») сбивают.

## Подвал

Мелко, моно, плотно. Хэштег события как колонтитул (`#ЕДА #СЕМЬЯ #МУЗЫКА` у Сытого Бабра) — дешёвый способ дожать интонацию в последнем экране.
